# ADR-0001：项目目录归用户所有

- 状态：Accepted
- 日期：2026-07-13
- 决策阶段：M0-A
- 影响阶段：M2、M3、M4

## Context

GameEditor 项目会包含视频、音频、图片、代理文件、缩略图和导出物，单个项目可能达到数 GB。Electron 的 `app.getPath('userData')` 位于 roaming AppData 语义下，适合应用配置和小型状态，不适合作为大型项目与媒体资产的默认存储位置。

项目还必须满足用户可见、可复制、可备份、可迁移和可在应用重装后继续使用。若项目数据散落在 `userData`、浏览器存储和外部绝对路径中，这些要求无法形成可验证的所有权边界。

## Decision

项目是用户选择位置中的独立目录，目录名使用 `<project-name>.gameeditor` 后缀。应用可以提供一个由用户配置的默认项目根目录，但不能把 `userData` 作为项目根目录或大型资产的隐式落点。

规范目录结构为：

```text
<user-selected>/<project-name>.gameeditor/
  project.json
  assets/
    originals/
    proxies/
  thumbnails/
  exports/
  .cache/
  .recovery/
```

`userData` 只保存应用级数据：

```text
%APPDATA%/GameEditor/
  config.json
  recent-projects.json
  logs/
  crash-dumps/
  migrations/
```

项目目录内的持久引用使用 POSIX 风格相对路径。`ProjectDocument` 不保存可用于绕过项目根目录授权的资产绝对路径。绝对路径只在 Main 进程的当前会话中解析，不通过项目文件或 Preload API 暴露给 Renderer。

Main 持有当前项目根目录授权，并在创建、打开、保存、导入、删除和另存为时重新校验目标路径。项目移动后，`project.json` 与项目内资产的相对关系必须保持有效。最近项目列表只是导航索引，不是项目内容的事实来源；路径失效时应允许用户重新定位，不能创建同名空项目掩盖错误。

“另存为”复制完整项目语义所需的文档与资产，并在新目录中完成后再切换当前项目。它不能只复制 `project.json`，也不能让新旧项目继续共享隐式外部绝对路径。

## Consequences

- 用户可以使用文件系统、备份软件或版本化工具管理完整项目，应用重装不会天然删除项目。
- 项目移动、磁盘盘符变化和跨机器迁移成为可测试场景；项目内相对路径降低了迁移成本。
- 应用必须处理目录不可写、磁盘空间不足、目录被移动以及最近项目条目失效等正常故障。
- 项目保存、资产复制和另存为必须遵守同一个根目录授权与路径校验规则，不能由各组件自行拼接路径。
- `.cache/`、`.recovery/` 和 `exports/` 的清理、备份及保留策略需要明确，但不得影响 `project.json` 与原始资产的所有权。

## Rejected Alternatives

### 把所有项目保存在 `userData`

拒绝。大型媒体会占用系统盘或 roaming 目录，且用户难以识别、迁移和独立备份项目。

### 把项目始终保存为单个 ZIP 或私有二进制包

拒绝。频繁保存大型容器会增加写放大、崩溃损坏和恢复成本，也不利于资产流式访问。ZIP 可以作为显式导出格式，不是工作目录。

### 只保存资产绝对路径，媒体留在任意外部位置

拒绝。绝对路径会在移动项目、换盘符或跨机器时失效，也扩大了项目文件可触达的文件系统范围。

### 让 Renderer 直接持有项目绝对路径并访问文件系统

拒绝。Renderer 按不可信进程处理，项目根目录授权和路径校验必须留在 Main。

## Verification Implications

本 ADR 在 M0 只形成决策证据，不提前实现 M2/M3。

- 创建项目测试必须证明用户可以选择目录，且应用不会把项目或媒体默认写入 `userData`。
- 目录布局测试必须证明 `project.json`、原始资产、代理、缓存、恢复文件和导出物落在规定边界。
- schema 测试必须拒绝资产绝对路径、路径穿越和非规范分隔符。
- 路径安全测试必须覆盖 `..`、绝对路径、UNC、junction、symlink、重解析点和编码后路径穿越。
- 另存为测试必须证明资产复制完成后才切换项目，失败时原项目与目标目录均保持可恢复状态。
- 移动整个项目目录后重新打开，所有项目内资产引用仍须有效。
- 1 GB 资产复制时 Renderer 不得出现超过 50 ms 的 I/O 阻塞，额外内存预算不超过 200 MB。
