# 通用剪辑器 P0 产品契约

- 日期：2026-08-04
- 状态：契约冻结；P0-1 技术切片已验证，P0-2 为下一条草案派工线
- 适用范围：GameEditor 通用多轨时间轴剪辑器
- 本文是新增产品文档，不改变当前源码、配置或编排控制面

## 1. 产品目标

用户能够创建或打开项目，导入可用媒体，将媒体放入时间轴进行基础剪辑，预览结果，并以明确的格式和状态导出。P0 交付一条可重复、可恢复、可验证的“项目 -> 资产 -> 时间轴 -> 预览 -> 导出”主链路，不承诺完整互动叙事编辑器。

## 2. 对象契约（冻结）

以下对象名、所有权关系和 P0 语义冻结。字段可通过版本化 schema 增补，但不得创建同义的第二套项目 JSON。

| 对象     | P0 定义                                | 关键不变量                                                                     |
| -------- | -------------------------------------- | ------------------------------------------------------------------------------ |
| Project  | 一个用户拥有的项目及其 ProjectDocument | 有稳定 id、schemaVersion、名称和时间信息；资产引用受项目根目录约束             |
| Asset    | 项目可引用的媒体文件及元数据           | 项目内 id 唯一；类型明确；缺失或未授权时不可伪装为可用                         |
| Track    | 时间轴中的同类媒体/标记容器            | 有稳定 id、名称、类型和有序 clips；可锁定、静音                                |
| Clip     | Track 内的时间区间与内容引用           | 起点和时长非负；不得越过时间轴或引用不存在的 Asset                             |
| Timeline | 轨道集合与播放范围                     | 时间单位统一为秒；播放头、选区、轨道顺序和片段排序可重建                       |
| Export   | 一次有标识的导出 Job 及其结果          | 明确格式、输入 revision、进度、取消、完成/失败状态和结果位置；失败不返回假地址 |

规范持久化根对象沿用 ADR-0002 的 ProjectDocument。revision、requestId、correlationId 是保存/传输元数据，不混入项目内容。Web 与 PC 通过 AppCapabilities 适配，组件不得直接依赖 Electron IPC、Node API 或桌面路径。

## 3. P0 核心用户旅程

1. 新建项目：用户输入名称并选择位置；系统创建有效空项目，失败时保留原因。
2. 打开项目：校验 schema、路径边界、实体引用和版本；未知高版本只读或拒绝打开。
3. 导入资产：在授权范围内复制或登记媒体，返回元数据与 Job 状态；取消/失败不产生可引用半成品。
4. 编辑时间轴：将资产放入 Track，移动、裁剪、删除 Clip，调整轨道顺序并保存；非法时间区间和失效引用被结构化拒绝。
5. 预览：移动播放头、播放/暂停并查看媒体；预览状态必须来自当前项目 revision。
6. 保存与恢复：失败提供稳定错误码和恢复位置；保存前保留可恢复副本，不能删除唯一正式文件。
7. 导出：选择已支持格式并启动 Export Job，看到进度并可取消；完成得到真实结果，失败/取消是明确终态。

## 4. P0 非目标

- 不实现完整非线性编辑：转场、关键帧、速度曲线、调色、混音台、代理媒体和专业编码参数不属于 P0。
- 不实现互动运行时、分支播放、变量执行、脚本执行、插件代码执行或在线发布。
- 不把 AI 剧本拆解、云端素材、OSS、更新器或账号系统纳入主链路。
- 不通过 mock 成功、示例 URL、假日志或静态 fixture 宣称导入、媒体处理或导出完成。
- 当前 M1 控制面关闭的项目存储、资产导入、Renderer adapter、FFmpeg render 只定义切片边界，不在本轮实现。

## 5. 结构化互动：P1 边界

P1 才允许把 Choice、ProjectVariable、trigger/choice/variable track 和场景图纳入可编辑产品能力。P0 可以保留只读兼容字段，或把未知互动内容显示为“未支持”，但不得执行 condition、actionCode、插件代码，也不得改变基础剪辑/导出语义。P1 需要另行冻结运行时模型、权限、沙箱、迁移和验收。

## 6. 能力与错误语义

available 只表示 adapter 提供入口，不表示本次 Job 成功。

| 错误码                     | 语义                     | 用户可见结果                      |
| -------------------------- | ------------------------ | --------------------------------- |
| UNSUPPORTED_CAPABILITY     | 当前环境不支持           | 禁用入口或显示不可用，不生成结果  |
| INVALID_INPUT              | 请求或实体不符合契约     | 保留编辑状态并指出可修复字段      |
| PROJECT_NOT_FOUND          | 项目失效或不存在         | 要求重新定位，不创建空项目        |
| PATH_NOT_AUTHORIZED        | 路径越出项目/授权边界    | 拒绝操作并保留 correlationId      |
| SCHEMA_VERSION_UNSUPPORTED | 版本过高或迁移链缺失     | 只读或拒绝打开，不覆盖原文件      |
| ASSET_MISSING              | Clip 引用的资产不可读    | 标记缺失，阻止相关预览/导出       |
| JOB_CANCELLED              | 用户或系统取消           | 终态为 cancelled，不显示完成      |
| JOB_FAILED                 | 探测、编码或写入真实失败 | 终态为 failed，保留诊断和恢复路径 |

## 7. 工程任务切片

| 切片             | 交付                                                                 | 验收证据                                        |
| ---------------- | -------------------------------------------------------------------- | ----------------------------------------------- |
| P0-1 Schema      | 版本化 Project/Asset/Track/Clip/Timeline/Export contract 与 fixtures | 合法、缺失引用、重复 ID、越界路径、未知版本测试 |
| P0-2 Project     | 新建、打开、保存、恢复、revision 与原子替换                          | round-trip、失败不破坏原文件、recovery fixture  |
| P0-3 Assets      | Web/PC adapter 的导入、取消、缺失和元数据                            | 真实文件复制/Blob、错误码和取消测试             |
| P0-4 Timeline    | 放置、移动、裁剪、删除、锁定/静音与播放头                            | 交互测试、引用和时间不变量测试                  |
| P0-5 Preview     | 当前 revision 的基础媒体预览                                         | 真实可播放 fixture、无资产时明确失败            |
| P0-6 Export      | 至少一个真实支持格式的 Export Job                                    | 真实输出文件、进度、取消、失败和重试验收        |
| P0-7 Integration | 串联主旅程并在 Web/PC 分别验证                                       | 从新建到真实导出的一条端到端记录                |

顺序为 P0-1 -> P0-2/P0-3 -> P0-4 -> P0-5 -> P0-6 -> P0-7。每个切片先声明能力、错误码和非目标；没有真实执行证据只能标记“已实现/未验证”。
