Product north star

产品主张

CinePlayStudio 首先是一款面向创作者的通用剪辑器：把素材、轨道、片段、字幕、音频和预览放在一条稳定的编辑闭环里。 结构化互动项目建立在这条基础能力之上，作为后续增强。
本月产品问题 用户能否不依赖额外说明，从导入素材走到剪辑、预览、保存并得到真实可播放的结果？
核心对象 5 项目、素材、轨道、片段、输出
编辑面 5 项目、素材、时间轴、检查器、播放器
核心路径 6 项目 → 素材 → 时间线 → 剪辑 → 预览 → 输出
本月 P0 7 项目、素材、轨道、片段、保存、预览、输出
产品原则 可用 先让创作者稳定剪出结果，再叠加互动能力
当前边界 P0-1 Schema 已技术验证，P0-2 项目存储待派发

Product principles

本月产品决策

每项需求都必须回到创作任务和产品对象，不从商业包装倒推功能。

01 / Editing

先把剪辑闭环做顺

素材、轨道、片段、时间线、预览和输出属于同一份项目；创作者可以从导入一路走到成片。

Asset Track Clip

02 / Creation

让每个编辑动作可理解

时间线负责编排，检查器负责细节，播放器负责验证；创作者能完成移动、裁切、分割、调整和预览。

Timeline Inspector Player

03 / Trust

失败必须真实可解释

保存、素材、预览和输出都要区分真实结果、fallback、mock 和暂不支持，不给假成功。

Error state Provenance No fake success

Core product loop

从素材到可播放成片

这是本月产品主线；结构化互动、AI、桌面和商业化都只能服务这条剪辑闭环。

01 / INPUT

项目

创建或打开项目，项目文件成为可恢复的工作上下文。

02 / MEDIA

素材

导入视频、音频、图片和字幕，并明确失效路径和素材状态。

03 / TIMELINE

时间线

把素材放到多条轨道，对齐时间、层级和顺序。

04 / EDIT

剪辑

移动、裁切、分割、删除和调整片段，并能看见编辑结果。

05 / REVIEW

预览

播放、定位、检查音画和字幕，发现问题后回到具体片段。

06 / OUTPUT

输出

保存项目并生成真实可播放结果；失败、取消和暂不支持都说清楚。

P01 项目与工程文件ProjectManager / ProjectDocument 原型已有 创作者可以建立、打开和管理一个持续工作的剪辑项目。 保留现有项目管理原型，补齐项目目录和恢复语义。
P02 素材库与媒体导入AssetManager / local assets 原型已有 视频、音频、图片和字幕能被找到、预览并放入项目。 先明确引用、复制、预览和失效素材的产品状态。
P03 多轨时间线Timeline / TimelineTrack / Clip 原型已有 素材可以按时间、层级和轨道关系组织成一个编辑结果。 冻结最小轨道类型、时序和片段显示范围。
P04 播放器与基础预览Player / seek / preview 原型已有 创作者能播放、定位并快速判断时间线是否符合预期。 补齐播放、定位、暂停、失败和回到编辑的状态。
P05 片段剪辑操作trim / split / move / delete P0 本月 创作者可以完成最常用的移动、裁切、分割、删除和排序动作。 先把核心剪辑动作做成可复现、可撤回、可预览的任务。
P06 检查器与属性编辑Inspector / clip properties P0 本月 用户能理解并调整当前素材或片段的属性，而不是猜测隐藏状态。 定义选中、修改、取消、应用和无效输入的反馈。
P07 素材状态与重新绑定path / relink / missing media P0 本月 素材换位置、失效或重新绑定时，创作者知道项目发生了什么。 明确项目外路径、缺失、替换和重新绑定的可见语义。
P08 保存、重开与恢复revision / recovery / migration P0 本月 项目属于用户，不被某台电脑、一次崩溃或一次浏览器刷新绑死。 当前 localStorage 只算原型事实，产品目标是可迁移项目目录。
P09 项目健康检查Diagnostics / media / timeline P0 本月 在输出前发现缺失素材、越界片段、无效属性和时间线问题。 每条规则都要能定位到素材、轨道或片段并可复查。
P10 真实媒体输出 JobFFmpeg / cancel / cleanup / diagnostics 工程等待 用户获得真实可播放的文件，并能诊断失败、取消和清理结果。 这是 P0 产品目标，但等待工程闸门；模拟日志不计入完成。
P11 结构化场景与分支Flowchart / SceneNode / Choice / Variable 互动增强 在通用剪辑基础上表达场景、选择、条件和不同内容路径。 先不抢占 P0；待剪辑闭环稳定后再冻结互动对象语义。
P12 剧本拆解到互动候选ScriptDecomposer / schema validation 互动增强 减少搭建互动内容的手工成本，但不替代人工审查和剪辑判断。 AI 只生成候选结构；等基础剪辑器完成后再进入候选池。

Product acceptance

月末产品判定

只判定产品闭环是否更清楚，不提前作商业发布结论。

Must be clearer

本月必须说清楚

  • 创作者如何从新建项目、导入素材走到可播放的时间线。
  • 移动、裁切、分割、属性调整和预览的核心编辑任务是否连贯。
  • 缺失素材、无效片段和时间线问题如何被发现并定位。
  • 保存、重开、恢复和真实输出各自的状态与失败语义。
  • 结构化互动项目为什么是增强项，而不是本月 P0。

Do not claim yet

本月不允许提前声称

  • 项目目录、素材导入、真实渲染和恢复已经产品化。
  • 源码中存在组件就等于用户可以稳定完成核心任务。
  • mock、fallback、示例 URL 或旧包可以替代真实能力证据。
  • 结构化互动项目、云协作、插件市场或运行时平台不属于当前 P0。
  • 商业化计划可以反向决定本月产品功能优先级。
