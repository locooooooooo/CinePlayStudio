# 0.5.0 可分发 PC MVP

> - 发布通道：封闭 Beta
> - 当前状态：planned
> - 内部映射：M4
> - 主要结果：安装版完成创建、导入、编辑、预览、保存和项目导出全链路

## 用户结果

受邀测试用户可以仅依赖安装版完成一个真实项目闭环：创建项目、导入本地素材、编辑互动流程、重启恢复、预览分支，并把项目数据与真实资产导出到指定位置。

## 本版本范围

- JSON、DOCX、ZIP 通过 Main service 和原生保存对话框导出。
- ZIP 使用流式归档，包含规范 manifest、项目文档和真实资产。
- 导出统一使用 Job 模型，提供进度、取消、错误码和临时文件清理。
- 建立结构化滚动日志、correlationId、诊断摘要和打开日志入口。
- 建立安装、启动、创建、打开、导入、预览、导出和卸载 smoke。
- 建立固定项目、500 节点、2000 clips 和 1 GB 资产性能基线。
- 为安装版建立核心 Electron E2E 和 Windows CI 产物证据。
- UI 对 unsupported 能力给出明确说明，不展示模拟完成状态。

## 非目标

- 不导出真实 MP4；该能力属于 `0.6.0`。
- 不生成可独立运行的互动游戏或播放器 EXE。
- 不提供云同步、OSS、协作、自动更新或任意插件执行。
- 不承诺 Premiere 或 DaVinci 级非线性剪辑。

## 封闭验证门槛

- 招募不少于 5 名符合目标用户画像、未参与实现的测试者，使用各自拥有且获准用于测试的素材。
- 至少 4 人仅依赖安装包和当期用户文档，独立完成创建、导入、编辑、重启恢复、预览和 ZIP 导出全链路。
- 工程人员可以观察和提问，但不能远程接管操作或现场修改项目数据来制造完成结果。
- 每个未完成案例必须登记阻塞步骤、错误码、数据是否可恢复和处理版本；数据丢失、安全越界或假成功一律阻断晋级。
- 仅记录经测试者同意的最小诊断信息，不复制其剧本和媒体内容进入发布证据。

## 硬验收

- 在一台干净 Windows 测试机上，仅通过安装包完成 PC MVP 全链路。
- JSON、DOCX 和 ZIP 保存到用户选择的位置，内容来自当前真实项目。
- ZIP 解包后包含规范 manifest 和实际资产，移动后可重新导入或打开。
- 取消导出不会留下伪装为成功的目标文件。
- 失败导出保留原项目，不覆盖已有成功文件。
- 1 GB fixture 导出不使用整包内存 Buffer，内存符合预算。
- 日志不包含 API key、Authorization、完整剧本或未脱敏用户路径。
- 安装、升级覆盖测试和卸载均不删除用户项目。
- M0-M4 的全部质量、安全和性能门禁通过。
- 封闭验证达到上述样本与完成门槛，结果按发布证据模板落档。

## 失败判定

- 任何核心步骤只能在 Web/dev 模式完成。
- ZIP 只包含配置、模拟日志或示例链接，不包含真实资产。
- 取消或失败任务仍显示完成。
- 安装版必须手工启动 Express 或配置开发环境才能工作。

## 退出条件

- 版本状态为 `verified`，形成可追溯的封闭 Beta 安装包。
- 已知问题不包含数据丢失、安全越界或假成功。
- 明确向测试用户说明本版本没有真实 MP4 输出。
- 允许 `0.6.0` 在稳定 Job 和媒体服务上实现最小真实渲染。
