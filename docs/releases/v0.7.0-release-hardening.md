# 0.7.0 发行加固

> - 发布通道：公开前 Beta
> - 当前状态：planned
> - 内部映射：M6-A
> - 主要结果：功能冻结后的产品达到候选版所需的稳定性、可理解性和合规基线

## 用户结果

首次使用者能够理解产品边界并完成核心创作闭环；高风险操作可撤销、可恢复或有明确确认，长时间使用不会因已知资源泄漏和状态错乱破坏项目。

## 本版本范围

- 冻结 1.0 功能范围，只修复缺陷和完成发行必需项。
- 决定并统一正式产品名、应用图标、厂商信息和版本展示。
- 从正式构建移除研发需求矩阵、仿真编译器和模拟 OSS 等内部界面。
- 完成首次启动、创建项目、导入旧数据和错误恢复引导。
- 为核心编辑命令提供撤销/重做，并明确不可撤销操作。
- 完成崩溃恢复矩阵、长时间稳定性和资源释放测试。
- 完成 100%、125%、150%、200% DPI 与最小窗口检查。
- 完成键盘操作、焦点、对比度和基础无障碍检查。
- 建立 Windows CI、核心 Electron E2E、安全测试和性能回归门禁。
- 完成依赖、FFmpeg、字体和示例素材许可清单。
- 完成隐私说明、日志脱敏、数据位置和卸载行为说明。
- 优化安装包与 unpacked 体积，记录无法移除的组成。

## 非目标

- 不增加新的编辑器功能、媒体轨道、云服务或插件系统。
- 不在本版本临时加入自动更新。
- 不用 UI 改版替代可靠性和测试修复。

## 首次使用验证门槛

- 使用冻结候选功能和拟公开文档，邀请不少于 5 名此前未使用过 CinePlayStudio 的目标用户。
- 至少 4 人无需工程人员解释界面或代操作，即可完成安装、创建、导入、分支预览、重启恢复、ZIP 导出和受支持 MP4 导出。
- 每个入口误解、恢复失败和边界误判都必须映射到产品缺陷、文档缺陷或明确非目标，不能只记录“用户不会用”。
- 任何导致核心旅程无法完成的共性问题修复后必须重新执行受影响场景。

## 硬验收

- 全量 unit、integration、Electron E2E、security、performance 和 packaged smoke 通过。
- 固定 8 小时编辑与预览测试无未解释崩溃和持续资源增长。
- 强制结束、系统重启、磁盘不足和只读目录恢复矩阵通过。
- 所有用户可见入口都对应真实能力或明确 unavailable 状态。
- 撤销/重做覆盖节点、分支、时间轴和属性编辑的核心命令。
- 不存在 P0 数据丢失、安全越界或安装阻断问题。
- 隐私、许可、第三方 notice 和数据目录说明通过发布评审。
- 应用 metadata 不再使用 AI Studio 模板说明或占位品牌。
- 路线总纲“发布前待决事项”中最晚关闭版本为 `0.7.0` 的决策全部落档。
- 首次使用验证达到上述样本与完成门槛。

## 失败判定

- 通过关闭测试、放宽性能预算或隐藏错误进入下一版本。
- 正式构建仍暴露模拟商业能力并允许用户触发。
- 已知数据损坏或安全问题仅登记为普通 known issue。
- 发行文档和安装包表现不一致。

## 退出条件

- 1.0 功能范围正式冻结。
- P0 为 0；P1 为 0 或有批准的发布阻断判断。
- 签名、发布源、支持渠道和回退方案准备完成。
- 允许生成 `0.9.0-rc.1`。
