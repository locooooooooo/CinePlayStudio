# 0.6.0 最小真实渲染

> - 发布通道：封闭 Beta
> - 当前状态：planned
> - 内部映射：M5
> - 主要结果：用户能把一个场景导出为真实可播放的 MP4 预览片

## 用户结果

用户可以选择一个场景，将一条主视频、字幕和可选音频导出为真实 MP4。任务具有可见进度，可以取消，失败时不会留下损坏成品。

## 输出边界

本版本固定支持：

- 单场景。
- 单主视频轨。
- 单字幕轨，采用受控字体烧录。
- 可选单音频轨。
- MP4 容器、H.264 软件编码基线和 AAC 音频基线。

更多视频轨、复杂混音、转场、滤镜、调色、批量队列和互动播放器输出不属于本版本。

## 本版本范围

- Main 管理 FFmpeg 子进程，使用参数数组和 `shell: false`。
- 建立渲染 Job、进度解析、取消、超时和进程退出码映射。
- 输出先写临时文件，成功后原子移动到目标位置。
- 失败、取消、崩溃和应用退出时清理临时文件。
- 软件编码作为可重复基线；硬件编码只做能力探测和显式选择。
- 字幕字体随包分发或由受控字体策略解析。
- 建立中文、空格、长路径和无音频输入测试。
- 完成 FFmpeg/FFprobe 二进制、codec 和字体许可复核。

## 非目标

- 不承诺多轨视频合成和专业剪辑能力。
- 不承诺硬件编码在所有 GPU 上可用。
- 不上传云端，不生成 CDN URL。
- 不把 MP4 当作可保留互动分支的发布格式。

## 真实用户验证门槛

- 至少 3 名封闭测试用户在不少于 3 台符合支持矩阵的机器上，用自己的真实场景完成至少 5 次 MP4 导出。
- 至少 4 次导出在不修改素材源文件的前提下成功，输出可播放，字幕、音频和时长符合本版本边界。
- 所有失败都必须能区分为不受支持输入、环境限制或产品缺陷，并给出错误码和恢复路径。
- 任何损坏原项目、覆盖既有成品、假成功或无法取消的问题均阻断晋级，不以总体成功率抵消。

## 硬验收

- 安装版输出的 MP4 可由系统播放器打开，音视频时长符合允许误差。
- 字幕内容、时间和中文字体显示正确。
- 0%、中途和完成前取消均不留下正式目标文件。
- FFmpeg 非零退出、磁盘不足、目标只读和输入损坏均返回稳定错误码。
- 软件编码在固定 fixture 上结果可重复，性能基线有记录。
- 未检测到硬件编码时自动回到软件基线，并明确提示，不伪造加速状态。
- 渲染期间编辑器保持可交互，进度事件经过节流。
- 真实用户验证达到上述门槛，失败分类和样本环境已落档。

## 失败判定

- 仍返回示例下载 URL或模拟日志。
- Renderer 直接运行 FFmpeg 或持有子进程句柄。
- 失败后损坏文件使用正式文件名留在目标目录。
- 只有开发机 PATH 上的 FFmpeg 可以工作。

## 退出条件

- 最小渲染在安装版达到 packaged verified。
- 输出限制已在 UI 和用户文档中明确。
- 功能范围冻结，进入 `0.7.0` 发行加固，不再扩展剪辑能力。
