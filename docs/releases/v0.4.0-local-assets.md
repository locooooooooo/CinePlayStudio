# 0.4.0 本地资产

> - 发布通道：内部 Beta
> - 当前状态：planned
> - 内部映射：M3
> - 主要结果：用户导入的本地媒体在重启和移动项目后仍能安全播放

## 用户结果

用户可以导入本地视频、音频、图片和文档。资产会真实复制到项目目录，不会被替换成远程示例 URL；项目重启或整体移动后，媒体引用仍然有效。

## 本版本范围

- 流式复制资产到 `assets/originals/`，使用临时文件和原子完成。
- 记录稳定 ID、内容 hash、`sizeBytes`、MIME 和项目相对路径。
- FFprobe 与缩略图生成为独立 Job，支持进度、错误和可取消语义。
- 建立 `gameeditor://` 安全协议、MIME、range request 和 seek。
- 建立项目根目录授权、规范化和路径包含检查。
- 支持安全删除、项目内回收策略和引用检测。
- 建立大文件导入、播放和内存性能基线。
- 清除产品默认流程对远程示例媒体的运行依赖。

## 非目标

- 不实现媒体转码或多轨渲染。
- 不上传 OSS，不生成公开 CDN URL。
- 不支持项目外部绝对路径作为正式资产引用。
- 不实现云端素材库。

## 硬验收

- 导入 1 GB 视频时 Renderer 保持可交互，内存符合预算。
- 导入完成前不会在项目文档中登记伪成功资产。
- 视频支持播放、range seek，重启项目后仍可访问。
- 移动整个项目目录后重新打开，资产引用仍然有效。
- `..`、绝对路径、UNC、编码穿越、junction、symlink 和重解析点逃逸全部失败关闭。
- 删除不能越过项目根目录，也不能静默破坏仍被使用的资产。
- 中文、空格和长文件名路径通过安装版测试。

## 失败判定

- 选择文件后只保存文件名或远程示例 URL。
- 大文件被整体读入 Renderer 或内存 Buffer。
- probe 失败后返回模拟元数据并标记成功。
- 协议可以读取未授权项目外文件。

## 退出条件

- 资产、协议、路径安全和性能测试通过。
- 项目重启与移动测试通过。
- 允许 `0.5.0` 打包真实项目资产并完成 PC MVP 全链路。
