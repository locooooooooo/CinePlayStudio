# 1.0.0 正式公开版

> - 发布通道：正式公开
> - 当前状态：planned
> - 内部映射：M6-C
> - 主要结果：用户可以从正式渠道获得一套稳定、可支持、边界清晰的 Windows 创作工具

## 正式承诺

1.0 用户可以：

- 在用户拥有的目录创建、打开、保存、恢复和迁移项目。
- 导入并管理真实本地媒体资产。
- 编辑场景节点、分支、变量、字幕和受支持的时间轴内容。
- 在应用内预览互动选择和声明式条件、动作。
- 导出 JSON、DOCX、包含真实资产的 ZIP 项目包。
- 导出单场景、单视频、单字幕、可选单音频的 MP4 预览片。
- 通过日志、诊断和恢复文档处理常见失败。

## 公开发布包

- 已签名并带可信时间戳的 Windows NSIS 安装包。
- SHA256、文件大小、版本号、构建 commit 和签名主体。
- Release notes、known issues 和系统要求。
- 快速开始、项目备份、迁移、恢复和卸载说明。
- 隐私说明、第三方许可、字体与媒体 notice。
- 支持渠道、问题报告模板和诊断收集边界。
- 停止发布、撤回下载和回退到上一候选包的操作手册。

## 明确不包含

- 完整多轨非线性视频剪辑和专业调色。
- 独立互动游戏播放器或一键生成游戏 EXE。
- 云同步、多人协作、OSS/CDN 发布。
- 自动更新。
- 任意 JavaScript 插件或不受限脚本执行。
- 未经验证的硬件编码保证。

## 正式发布验收

- 公开下载的字节与最终通过验收的 1.0 签名产物一致；该产物基于已批准的 RC 源码状态，不包含新的行为变更。
- 对应 RC 已满足观察期、外部样本和核心旅程完成率门槛，并链接完整发布证据。
- 在干净 Windows 10/11 测试机完成核心创作全链路。
- 安装、覆盖安装、卸载和重新安装不会删除用户项目。
- 项目、资产、导出和 MP4 失败路径不会假成功或破坏原数据。
- P0、P1 缺陷为 0；其余 known issues 不违背正式承诺。
- 签名、SmartScreen、隐私、许可和发布主体通过最终检查。
- 文档中的按钮、路径、格式、限制和产品实际行为一致。
- 发布渠道可以执行撤回和回退，并已经完成演练。
- 正式发布清单记录下载 URL、SHA256、文件大小、签名主体、时间戳、源码 commit、文档版本和批准人。

## 停止发布条件

出现以下任一情况立即停止或撤回发布：

- 用户项目丢失、静默损坏或升级后不可恢复。
- Renderer、IPC、协议或路径校验存在可利用的安全越界。
- 安装器签名无效、下载 hash 不一致或发布主体异常。
- 核心安装版流程依赖开发服务器、外部示例资源或模拟结果。
- 许可、隐私或第三方资产授权不完整。

## 发布后策略

- `1.0.x` 只用于兼容性、安全和缺陷修复，不新增产品能力。
- 安全或数据损坏问题优先发布补丁并同步恢复建议。
- `1.1.0` 及以后另行立项，不自动继承云、更新或插件范围。
- 发布后复盘记录安装成功率、崩溃、数据恢复和主要用户阻塞，但不在未获同意时上传用户内容。
- 正式发布后前 72 小时保持可执行的撤回与热修复值守，并在第 7 天和第 30 天完成一次发布复盘。
- 复盘数据来自发布渠道统计、用户主动反馈和明确同意的诊断信息；没有数据时记录 `unknown`，不推算虚假成功率。

## 完成定义

只有正式渠道可下载、全部发布验收通过、支持与回退入口可用时，版本状态才能从 `verified` 更新为 `released`。
