# ICE-02 本地资产与许可

> 状态：planned_not_dispatched
>
> 目标里程碑：E3 本地资产
>
> 上游依赖：ICE-01 verified。

## 目标

让用户的真实视频、图片、音频和文档以可追溯、可移动、可重开的形式进入项目目录；同时记录最小许可状态与资源完整性。

## 范围

- 原生选择器授权、Main 层路径/类型/大小校验、流式复制与内容 hash。
- `assets/originals`、缩略图、代理缓存与相对路径引用。
- FFprobe metadata、缺失资源、重复资源、损坏资源和许可证状态。
- 中文、空格、长路径、符号链接、项目外路径与 1 GB fixture。

## 非目标

- 自动下载网络素材、抓取平台视频、云存储、AI 生成素材或商用权利判断。
- 多轨剪辑、FFmpeg 渲染、跨端构建。
- 仅登记 FileReader 元数据却将远程示例 URL 当成导入结果。

## 计划文件范围

派工前指定资产服务、受控 IPC、ProjectDocument 资产字段、fixture 与测试目录。禁止修改 Runtime 构建、发布文档或未授权的 UI 大改。

## 验收

1. 四类真实文件被复制到项目目录，重开和项目移动后仍可预览/定位。
2. 每个资产有稳定 ID、相对路径、hash、大小、类型、时长/尺寸和可用性状态。
3. 非法路径、损坏文件、符号链接逃逸和项目外删除被拒绝或显式标为缺失。
4. 1 GB fixture 不让 Renderer 整包读入内存或长时间阻塞。
5. 不显示远程示例、mock metadata 或伪造成功结果。

## 停止条件

资产真实字节、项目目录包含性或恢复语义任一项未通过时，不进入 E4 时间线。
