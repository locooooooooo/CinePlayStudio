# ICE-05 项目健康检查

> 状态：planned_not_dispatched
>
> 目标里程碑：E4 L1 创作与互动 Runtime
>
> 上游依赖：ICE-01、ICE-03、ICE-04 verified。

## 目标

在构建前发现影游项目中最昂贵的内容错误，并把问题定位到场景、轨道、clip、变量或构建目标。

## 规则范围

- 断链、不可达场景、无出口场景、无入口场景、结局覆盖不足。
- 缺失/未绑定资产、资源类型不匹配、clip 越界、字幕/互动触发冲突。
- 未声明变量、条件引用无效、动作目标无效、存档兼容冲突。
- 目标平台不支持的资源或构建配置。

## 非目标

- 用 AI 评价故事质量、自动改写剧本、执行用户脚本或自动修复项目。
- 取代人工导演、编剧或版权审核。

## 验收

1. 每条规则有 severity、正反 fixture、定位 ID、修复建议和稳定错误码。
2. 同一项目 revision 的检查结果可重复；检查不修改项目。
3. 用户修复后可重新检查，结果按 revision 区分。
4. 构建阻断级问题不能被 UI 静默忽略或以 mock 成功绕过。

## 停止条件

规则无法提供 fixture 或稳定定位时，不将其纳入正式发布阻断项。
