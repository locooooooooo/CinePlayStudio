# ICE-07 PC Player

> 状态：planned_not_dispatched
>
> 目标里程碑：E6 PC Player
>
> 上游依赖：ICE-06 verified。

## 目标

把同一 Web 互动包封装成受控 Windows Player，让观众在支持的 Windows 环境离线启动、选择、存档和导出最小诊断信息。

## 范围

- Player 宿主、资源协议、窗口、全屏、最小存档、日志/诊断与安装包。
- 构建包完整性验证、启动、双路径、存档、缺失资源、卸载 smoke。
- 支持矩阵、安装/卸载边界与故障恢复说明。

## 非目标

- 编辑器功能、任意本地文件访问、应用自动更新、跨设备云存档。
- 将编辑器 Electron 壳直接宣称为观众 Player。

## 验收

1. 固定 Web build 在干净 Windows 环境安装后无需开发服务即可运行。
2. Runtime 行为、存档兼容和错误状态与 Web 基线一致。
3. 安装、卸载、缺失文件和日志导出不删除用户项目或泄露敏感信息。
4. 安装包、版本、hash、Windows 版本、双路径结果和独立验证记录齐全。

## 停止条件

如果只能启动编辑器、只能开发机运行或依赖未受控本机环境，不能进入 E6。
