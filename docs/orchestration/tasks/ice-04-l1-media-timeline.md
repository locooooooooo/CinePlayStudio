# ICE-04 L1 媒体时间线

> 状态：planned_not_dispatched
>
> 目标里程碑：E4 L1 创作与互动 Runtime
>
> 上游依赖：ICE-02、ICE-03 verified。

## 目标

实现影游所需的受控媒体编排：单主视觉、单 BGM、单 SFX、单字幕与单互动轨，支持裁切、拆分、移动、保存、重开和路径预览。

## 范围

- 明确轨道类型、clip 时间范围、资源引用、编辑命令和 revision 语义。
- 视频/图片主视觉、音频、字幕、选择触发点与场景转场。
- 预览同步、素材缺失状态、时间线 fixture 与编辑操作 E2E。

## 非目标

- 专业多轨剪辑、复杂混音、调色、自由关键帧、滤镜市场、自动卡点。
- MP4 交互导出、云渲染、Android/PC Player。

## 验收

1. 支持矩阵内的单场景可完成添加、裁切、移动、删除、保存、重开和预览。
2. clip 不能越出场景时长、错误引用或落到错误轨道；失败有稳定错误码。
3. 字幕、音频、选择与主视觉在预览时间线上按同一 revision 运行。
4. 缺失媒体、非法时间、重复 ID、未保存修改和播放错误均有明确状态。
5. 500 节点、2,000 clips fixture 的响应基线被记录，不以主观流畅度代替。

## 停止条件

单轨保存/重开或互动预览未稳定前，不增加多轨、特效、GPU 编码或云端功能。
