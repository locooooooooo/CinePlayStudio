# ICE-09 设计合作与付费试点

> 状态：planned_not_dispatched
>
> 目标里程碑：E8 Studio Beta
>
> 上游依赖：ICE-05、ICE-06 verified，以及拟售目标平台对应的 Player 已 verified。

## 目标

验证真实团队是否愿意为可靠的影游创作、构建和交接链付费，而不是为一次性人工代制作付费。

## 范围

- ICP 筛选、设计合作协议、素材权利确认、试点范围、培训、支持窗口与退出规则。
- 每个试点的项目规模、目标平台、用户旅程、错误登记、验收与付款/续用记录。
- 脱敏案例、价格反馈、服务/订阅分账与 Go/No-Go 决策材料。

## 非目标

- 无限制定制开发、替客户制作完整作品、承诺未验证目标平台或云服务。
- 未经书面授权使用客户剧本、媒体、联系方式或诊断内容。

## 验收

1. 至少 3 个设计合作团队带入真实且获授权的样本，按支持矩阵完成核心旅程。
2. 至少 2 个团队对下一项目作出付费/续用决定，且理由可区分产品价值与人工服务。
3. 每个未完成案例记录阻塞点、错误码、数据恢复结果、支持投入与处理版本。
4. 试点退出时客户可导出项目与资产，不被平台锁定。
5. 案例、价格和收入只使用获得授权的脱敏证据。

## 停止条件

若试点只能依赖作者现场接管、只愿为定制代做付款，或存在未关闭数据/版权风险，则 E8 保持 pilot_only 或 blocked。
